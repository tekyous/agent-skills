# Tekyous plugin

Tech stacks from your agent, grounded in [Tekyous](https://tekyous.dev/agents): the Tekyous MCP server (a developer
tools catalogue, curated stacks, stack recommendations and tech stack diagrams) and two skills.

- **tech-stack-recommendation** helps you choose a stack or one tool for your project, using Tekyous's catalogue and
  curated stacks (scores with their reasoning, pricing, pros and cons) and checking the picks against your project's
  constraints.
- **tech-stack-diagram** reads your project, draws its tech stack with each tool's logo, saves the picture and adds it
  to your README, linked to the same diagram in the Tekyous builder, fully editable.

The MCP server is read-only and needs no account or API key. It receives only what the agent sends it (the diagram,
search terms, tool names), never your files or keys. Install steps for every agent, and what the plugin sends where:
[github.com/tekyous/agent-skills](https://github.com/tekyous/agent-skills). Privacy: [tekyous.dev/privacy](https://tekyous.dev/privacy#mcp-server).
